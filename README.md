## Em que estou trabalhando

Os repositórios são privados porque contêm dados de operação. Aqui está o que cada um faz.

| Projeto | O que resolve | Tecnologias |
|:--|:--|:--|
| **Portal** | Plataforma interna que centraliza ferramentas e fluxos da operação | Python, SQLite |
| **Dashboard** | Painel de dados pronto para reuniões, com avaliação de atendimento por IA a partir de conversas de CRM | Python, BigQuery, LLMs |
| **Nexus** | Assistente de IA que monitora e protege sites pela API da Cloudflare | Python, Cloudflare API |
| **AD-Insights** | Análises e inteligência de dados para apoiar decisões | Python |
| **Jarvis local** | Assistente pessoal de IA que roda localmente e orquestra modelos especializados | Python, Linux |

## Princípios

- **Problema primeiro, tecnologia depois.** IA só entra quando resolve algo real.
- **Automatizar o repetitivo**, para o time focar no que exige criatividade e relacionamento.
- **Dado sem decisão é só planilha.** Todo painel precisa responder a uma pergunta de negócio.
- **Documentar faz parte de entregar.**
